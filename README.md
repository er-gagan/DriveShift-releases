# DriveShift releases

This repository publishes DriveShift Windows installers only.

Application source code is not stored here. It stays in a private repository.

Download the latest installer from [Releases](https://github.com/er-gagan/DriveShift-releases/releases).

An installed copy checks this repository once each time DriveShift is opened. It does not check again until the next time the app is opened. When a newer version exists, DriveShift downloads it and installs it the next time you quit and open the app.
